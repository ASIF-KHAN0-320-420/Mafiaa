## ⚡ INSTALL TOOL ON TERMUX


## Update Packages

- `pkg update`
- `pkg upgrade`

## Install Python and Git

- `pkg install python`
- `pkg install git`

## Install Requirements

- `pip install requests`
- `pip install bs4`
- `pip install futures`
- `pip install mechanize`
